# Interface 

Interface defines the Serializer, Client & Server abstractions for a REST style architecture to bridge between 2 Systems – with the Server system connecting through to the remote storage. RMTC Core provides a concrete Flask based implementation of these. 

RMTC’s domain lends itself naturally to web interfaces – this is still an early capability as it primarily operates in a traditional VFX Python session.
