# New Logo

## Feature Description

RMTC currently lacks a cohesive visual identity — there is no branded logo for the project. A professionally designed logo will improve project recognition within the ASWF ecosystem and broader VFX community, serve as a visual anchor for the website/documentation, and establish the foundation for consistent branding across tools and materials. This is a design-led initiative, not a code feature.

## Criticality

Low. A logo improves project presentation and community perception but does not block technical functionality or adoption. This is primarily a branding/marketing concern for the pre-Alpha stage.

## T-Shirt Size

S. This is a bounded design task (single designer/design firm, typically 1-2 weeks). Implementation is minimal: placing the logo file in `docs/images/` and updating README/website references.

## How to Implement

1. **Design Brief & Governance**: Work with ASWF design/branding guidance (similar to other ASWF projects — e.g., OpenVDB, USD) to define brand requirements (logo style, color palette, usage guidelines). Confirm compliance with ASWF branding standards.
2. **Design Exploration**: Engage a designer (ASWF-recommended or contracted) to produce 2-3 concept variants. Key themes: "Rongotai" (Wellington location / sea/sound), "Model Train Club" (collaboration, precision), VFX/AI context (stylized tensors, film-strip elements optional).
3. **Review & Approval**: Present to RMTC maintainers + TSC for feedback; iterate if needed (1-2 rounds typical).
4. **Asset Delivery**: Finalize logo in multiple formats (SVG for scalability, PNG/JPG for raster fallbacks, favicon for web). Include usage guidelines (minimum size, clear space, color/monochrome variants).
5. **Integration**: Place files in `docs/images/rmtc_logo.*` (following existing image convention). Update `README.md` to display the logo in the header.

## Considerations

- **ASWF Brand Alignment**: Check ASWF trademark and branding guidelines to ensure the logo is compatible with ASWF badging/attribution.
- **Multi-use**: Logo should work at various sizes (README badge, favicon, website header, printed materials) and in light/dark modes if the website adopts theme switching.
- **Out of Scope**: Deploying to all marketing channels, merch design, animated variants — initial delivery is static logo files + usage guidelines.
- **Timing**: This task can proceed in parallel with website development but ideally completes before the website is published.
