Future

Where RMTC Might Go Next

RMTC is not a finished thing, there is work - here are a few areas that the community can help us to build.

Provenance

Stronger Guardrails

Explore license and permission checks at training and inference execution time. Watermarking through C2PA and other asset specific representations, automatically applied on publish. Generalize the builder/publisher pattern beyond Nuke into a pluggable build-publish-import workflow.

Workflows

DCC & AI Workflow Integrations

Exposure to popular DCCs and AI workflow session systems to help with implicit provenance tracking, the ability to trace inferences back to their sessions collectively.

Releases

Production Release Process

CI/CD pipeline, versioning discipline, and TSC-governed release-approval workflow. Comprehensive testing suite covering VFX formats (EXR, USD, DCC integrations). Project branding and visual identity.

Security

Credential & Access Control

Remove plaintext credential storage and integrate with secrets managers. Add user/context identity and role-based authorization so System doesn't trust every caller. Support for enterprise credential backends.

Scheduling

Distributed Training & Inference

Unified, pluggable job scheduler replacing duplicated train/infer code. OpenCue and Deadline backend implementations for render-farm scale. Docker-containerized tasks with UV-managed environments for reproducible farm workers.

Asset Formats

Extended Format Support

Multi-part EXR, arbitrary channel counts, and optional deep EXR support. Point cloud asset type with PLY and Gaussian-splat I/O. Tensor format audit and Camera tensor bug fixes.

Platforms

Multi-OS & Linux Variants

Native Windows build support via CMake and removal of POSIX-only assumptions. Validation on Rocky Linux and other enterprise distributions. Cross-platform CI ensuring builds work everywhere studios run.

Code Quality

Production Hardening

Systematic fix-ordering for cataloged bugs and systemic flaws. Triage of TODOs and stubs for production readiness. Asset manager refactoring to split read, write, pipeline, and publish concerns into independent interfaces.

Frontends

Multi-Interface Access

Hardened Flask REST API for remote System access. In-DCC plugins for Nuke, Maya, and Houdini enabling real-time inference. Lightweight JavaScript UI for model/run browsing. JIRA integration for model approval workflows.

Runtime Performance

C++ Tensor Layer & ONNX

Comprehensive ONNX export with multiple packager backends. C++ mirror of Process/ProcessStack for low-latency tensor marshaling in DCCs. pybind11 bindings and C++ Factory for zero-copy inference paths.
